## 01 — About Me

I'm a Business Information Systems student with an interest in Data Analysis and UI/UX Design. I enjoy exploring how data can be transformed into meaningful insights and how thoughtful design can create better digital experiences.

Through various projects and learning experiences, I'm continuously developing my technical, analytical, and creative skills to understand and solve problems through technology.

- 🔍 **Currently Exploring:** Data Analysis, Data Visualization, and Interface Design.
- 📚 **Learning Focus:** Data Science, Data Visualization, and UI/UX Design.
- 🛠️ **Building:** Projects that combine data analysis and digital design.
- 🌱 **My Approach:** Always learning, exploring, and growing through every experience.
